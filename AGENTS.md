# Project Agent Instructions

- `Agent Memory/00 Dashboard.md`
- `Agent Memory/Agent Memory.md`

If these files exist, read them for durable user preferences, project context, current priorities, decisions, known issues, and important workflows. These instructions apply to Codex and every other authorized project agent.

Treat everything under `Agent Memory/` as local, private memory. Do not commit it, quote it unnecessarily, or expose sensitive details unless the user asks.

For memory bootstrapping, updates, audits, and agent handoffs, follow:

- `Agent Memory/Agent Workflows/NyxSuite Shared Memory Master Prompt.md`

When finishing meaningful work, offer to update Agent Memory with stable facts only: decisions, preferences, recurring workflows, important paths, verified fixes, known issues, test evidence, and unresolved follow-ups. Avoid storing secrets, access tokens, credentials, account data, or one-off chatter.
